# 运维面板 UI 设计规范（v1）

- 状态：设计定稿，待实施
- 适用：`web/`（Vue 3.5 + TypeScript + Element Plus 2.14）
- 依据：`ui-ux-pro-max` 检索结果（Data-Dense Dashboard、Minimalism & Swiss、Dashboard Data 字体配对、UX 指南）+ 本项目 Spec §8 的硬性交互契约
- 目标读者：实现该面板的前端/全栈工程师

---

## 0. 设计摘要

| 维度 | 决策 |
| --- | --- |
| 风格 | **Data-Dense Dashboard + Swiss Minimalism**：信息密度 8/10，装饰性元素为零 |
| 主题 | **深色默认**（机房/NOC 长时间盯屏），浅色可切换；两套均达 WCAG 2.2 AA |
| 品牌色 | 蓝 `#2563EB` 只用于「操作/链接/焦点」；**绿色保留给"健康/成功"状态**，避免保存按钮看起来像状态灯 |
| 字体 | 中文系统栈（PingFang/微软雅黑/Noto Sans SC）+ 等宽栈（JetBrains Mono/Fira Code）；**不加载 Web Font**（局域网/离线优先） |
| 动效 | 120–200ms `ease-out`，仅状态反馈；**不做滚动入场动画**（数据面板的滚动动画只会制造延迟感），支持 `prefers-reduced-motion` |
| 密度 | 行高 36px 表格、12–14px 正文、8–12px 卡片内边距、24px 页面留白 |
| 图标 | Element Plus Icons（SVG），禁止 emoji 充当图标 |
| 布局 | 顶部品牌栏 56px + 横向主标签 44px + 内容区；底部 sticky 操作栏 |

### 被否决的方案（含原因）

| 方案 | 否决原因 |
| --- | --- |
| 侧边栏导航 | Spec §8 明确要求横向主标签，九个入口窄屏可滚动、不折叠 |
| 卡片阴影堆叠 / 毛玻璃 | 数据密集页面里阴影降低可读性；改用 1px 边框 + 两层表面色区分层次 |
| 滚动入场（scroll reveal） | 运维面板首屏即数据，滚动淡入会让"刷新后看不到内容"；仅保留状态过渡 |
| 绿色作为主按钮色 | 与"扫描器健康/成功"语义冲突，用户会把操作按钮误读为状态 |
| Web Font（Fira/Noto from Google） | 面板可能部署在无外网局域网；改用系统字体栈，等宽字体缺失时回退 `ui-monospace` |
| 图表/仪表盘装饰 | 本项目只有状态、日志、表格；加图表是无数据支撑的装饰 |

## 1. 设计原则

1. **状态真实性优先于美观**：任何"实时/成功/已保存"都必须有服务端依据（读取时间、mtime、hash、连接状态）；数据缺失显示空态/错误态，绝不显示假数据。
2. **一眼可判断**：顶部状态条常驻「扫描器 / 轮次 / 最后更新 / 账号」；页面内危险操作与生效方式用文字标签，不只靠颜色。
3. **密而不挤**：8px 基准网格；同类信息成组，组间 24px；表头/操作栏 sticky。
4. **保守的动效**：只对"状态变化"做 120–200ms 过渡（保存结果出现、连接状态切换、行 hover）；不做位移动画。
5. **键盘与读屏是默认路径**：所有操作可 Tab 到达、Esc 关闭弹层、焦点可见；状态变化用 `aria-live` 克制播报。
6. **中文优先的排版**：正文用系统中文字体，数字/IP/hash/日志用等宽 + `tabular-nums`，避免列对齐抖动。

## 2. 信息架构

```
/                     总览
/config               参数
  ├ 扫描参数（探测端点 / 探测参数 / 采样 / 输入输出 / 调度 / 运行身份）
  ├ 发布与代理（发布 / 网络代理）
  └ 只读设置（镜像 / 容器名 / 面板）
/schedule             调度
/runs                 运行
  ├ 立即运行（实时输出）
  └ 历史轮次
/logs                 日志
  ├ 实时日志
  └ 下载
/outputs              产物
  ├ 全部 / 订阅列表 / 明细表
/library              IP 库
  ├ 编辑
  └ 备份
/publish              发布
  ├ 参数
  └ 最近结果
/system               系统
  ├ 账号 / 审计 / 容器 / 关于
/login /setup         认证
```

- 顶部主标签固定九个，顺序固定；当前标签用 2px 底边 + 加粗，不用下划线动画。
- 页内子标签使用 Element Plus `el-tabs`，`lazy` 渲染，避免隐藏页重复 DOM id 与表单状态。
- URL 与标签一一对应，可刷新、可收藏（面板已实现 SPA 深链接回退）。

## 3. 视觉语言

### 3.1 颜色 Token

深色为默认值；浅色通过 `html[data-theme="light"]` 覆盖。所有 token 以 CSS 变量暴露，Element Plus 通过 `--el-*` 映射复用。

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#0F172A` | `#F5F7FA` | 页面背景 |
| `--surface` | `#1B2336` | `#FFFFFF` | 卡片、表格、栏 |
| `--surface-2` | `#272F42` | `#EEF2F7` | 次级区域（表头、代码块、hover） |
| `--border` | `#334155` | `#E2E8F0` | 分隔线（装饰性） |
| `--border-strong` | `#64748B` | `#94A3B8` | 输入框/可交互边界（≥3:1） |
| `--text` | `#F8FAFC` | `#0F172A` | 正文 |
| `--text-muted` | `#94A3B8` | `#475569` | 次要说明、时间戳 |
| `--primary` | `#2563EB` | `#2563EB` | 主操作按钮、链接、选中态 |
| `--primary-hover` | `#3B82F6` | `#1D4ED8` | hover/active |
| `--on-primary` | `#FFFFFF` | `#FFFFFF` | 主按钮文字 |
| `--focus` | `#60A5FA` | `#2563EB` | 焦点环（2px + 2px offset） |
| `--success` | `#22C55E` | `#15803D` | 成功/健康 |
| `--warning` | `#F59E0B` | `#B45309` | 需重启/降级 |
| `--danger` | `#EF4444` | `#B91C1C` | 失败/核对不一致/危险操作 |
| `--info` | `#60A5FA` | `#1D4ED8` | 中性提示、链接信息 |
| `--log-bg` | `#0B1220` | `#0B1220` | 日志/终端区（两种主题都保持深色） |

**状态语义映射（唯一口径）**

| 语义 | 颜色 | 文案示例 |
| --- | --- | --- |
| 正常运行 / verified / done | success | 扫描器在线、核对通过、完成 |
| 需要注意 / restart_required / unavailable / running | warning 或 info | 已保存，需重启、无法核对、运行中 |
| 失败 / mismatch / interrupted / 5xx | danger | 核对不一致、失败、中断 |
| 中性 / 只读 / 未开始 | muted | 只读、尚无记录 |

- **禁止只用颜色表达状态**：标签必须带文字，图标仅作辅助。
- `running` 使用 info 蓝而非绿色：绿色只表示"已确认的健康/成功"。

### 3.2 对比度（已按 WCAG 2.2 计算）

| 组合 | 比值 | 结论 |
| --- | --- | --- |
| 正文 `#F8FAFC` / `#0F172A` | 17.06:1 | AA/AAA |
| 次要文字 `#94A3B8` / `#1B2336` | 6.11:1 | AA |
| 主按钮 `#FFFFFF` / `#2563EB` | 5.17:1 | AA |
| 成功 `#22C55E` / `#0F172A` | 7.83:1 | AA |
| 警告 `#F59E0B` / `#0F172A` | 8.31:1 | AA |
| 危险 `#EF4444` / `#0F172A` | 4.74:1 | AA |
| 输入边界 `#64748B` / `#1B2336` | 3.29:1 | 非文本 ≥3:1 |
| 浅色正文 `#0F172A` / `#FFFFFF` | 17.85:1 | AA/AAA |
| 浅色次要 `#475569` / `#FFFFFF` | 7.58:1 | AA |
| 浅色成功/警告/危险文字 | 5.02 / 5.02 / 6.47:1 | AA |

> 提示：亮绿色 `#22C55E` 只用于深色背景；浅色主题改用 `#15803D` 文字色，避免白底对比不足。

### 3.3 字体与字号

```css
--font-sans: "Inter", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "Fira Code", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

| 层级 | 字号/行高 | 权重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 20 / 28 | 600 | 每页 h1 |
| 区块标题 | 14 / 20 | 600 | 卡片 header、折叠面板标题 |
| 正文 | 13 / 20 | 400 | 表单标签、说明 |
| 辅助 | 12 / 18 | 400 | 默认值、时间戳、来源标签 |
| 数字/标识 | 13 / 20 | 500 + `tabular-nums` | IP、端口、hash、延迟、退出码 |
| 日志 | 12 / 18 | 400 + 等宽 | 实时输出、容器日志 |

- 不使用 700 以上字重（中文字体过粗会糊）。
- 所有数字列（延迟、大小、耗时）启用 `font-variant-numeric: tabular-nums`。
- 长文本（diff、错误摘要）允许换行，`overflow-wrap: anywhere`，绝不横向溢出。

### 3.4 间距、圆角、层次

- 间距基准 4px：`4 / 8 / 12 / 16 / 24 / 32`；卡片内边距 12–16，页面边距 20–24。
- 圆角：按钮/输入 6px，卡片 8px，标签 4px（pill 用 999px），抽屉 0（贴边）。
- 层次只靠三件套：`surface` 色差、1px `border`、8px 间距；**不使用大阴影**；浮层（dropdown/drawer）允许 `0 8px 24px rgba(0,0,0,.35)`。
- 表格：行高 36px，表头 sticky，hover 用 `--surface-2`；不设斑马纹（与 hover 冲突）。

### 3.5 动效

| 场景 | 时长/曲线 |
| --- | --- |
| hover/active | 120ms ease-out |
| 状态标签切换、保存结果面板出现 | 160ms ease-out（opacity + 4px 位移） |
| 抽屉/对话框 | 200ms ease-out |
| SSE 连接状态点 | 呼吸动画仅用于 `connecting`，400ms，`reduced-motion` 下静止 |

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
```

禁止：宽度/高度动画、整页淡入、滚动触发动画、日志逐行闪烁。

### 4.1 顶部品牌栏

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 左 | `CF` 方块 logo + 「Cloudflare 优选 IP 扫描器 · 运维面板」 | 点击回总览 |
| 中右 | 状态条：扫描器（在线/离线/不可用）、轮次（空闲/运行中）、最后更新时间 | 30s 轮询 `/api/overview`；失败时状态条变 danger 并显示原因 tooltip |
| 右 | 账号菜单：账号与系统 / 退出登录 | 退出后回 `/login` |

- 状态条永远显示**最后成功更新时间**；超过 2 个轮询周期未更新时追加「数据可能过期」。
- 离线原因不截断：hover/focus 显示完整文本（tooltip 最大 320px，可换行）。

### 4.2 主标签

- 横向排列、可滚动，禁止折叠成「更多」菜单（九个入口必须常驻可达）。
- 键盘：`←/→` 在标签间移动焦点，`Enter/Space` 进入；当前页 `aria-current="page"`。
- 窄屏（<768px）：隐藏副标题，标签保持 44px 高、水平滚动并加渐隐边缘提示。

### 4.3 内容区与操作栏

- 页面统一结构：`h1 + 右侧页级操作` → 状态/错误条 → 主内容 → 底部操作栏（表单类页面）。
- 底部操作栏 sticky 于视口底部（`bottom: 0`），显示「未保存 N 项」+ 取消/保存；保存中按钮 loading 且禁用重复提交。

## 5. 组件规格

### 5.1 StatusPill（状态标签）

- 形态：圆点/图标 8px + 文案，`--surface-2` 底、1px 边框。
- 尺寸：24px 高，12px 字号，左右 8px。
- 不单独用颜色：`● 运行中`、`● 已核对通过`、`● 中断`。

### 5.2 MetricCard（总览卡片）

- 标题（12px muted）+ 主值（20px 600）+ 辅助行（12px muted，可含时间）。
- 高度自适应，四张一行（≥1280），两行两列（768–1279），单列（<768）。
- 主值为状态时用 StatusPill，不用大色块。

### 5.3 ParamField（参数控件）

| kind | 控件 | 输入/展示规则 |
| --- | --- | --- |
| `bool` | `el-switch` | 立即更新本地值，不自动保存 |
| `int` / `float` | `el-input type=number` | 空值回填 0；失焦不提交 |
| `ports` / `csv_int` | 文本输入 | 逗号分隔；显示时 join(`,”`)；非法字符交由后端 422 |
| `str` / `path` / `cron` | 文本输入 | 等宽字体仅用于 cron 与路径 |
| `secret` | 密码输入 | 已配置时占位「已配置；留空表示不修改」，清空 = 显式清空 |
| `read_only` | 禁用输入 | 右侧「只读」标签，附命令提示 |

每个字段上方一行：`标签 + 生效方式标签（下一轮/热重载/需重启）+ 来源（来自 .env / 默认值）+ 只读`；下方：帮助文本（12px muted）+ 默认值。
**不显示明文密钥**；`configured` 状态用文字，不用颜色区分。

### 5.4 SaveResultPanel（保存结果）

固定出现在表单下方（不是 toast）。信息层级：

```
保存结果                                                [关闭]
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ 写入 已写入  │ 核对 已核对通过 │ 下次执行 18:30 │ 调度 已热重载 │
└──────────────┴──────────────┴──────────────┴──────────────┘
[变更表：参数 / 原值 / 新值 / 生效方式]
[mismatch：差异列表（期望 vs 实际）]
[warnings：黄色提示列表]
[重新核对] [立即执行一轮] [重启扫描容器（仅 restart_required）]
```

四态文案与视觉：

| `verification.status` | 颜色 | 文案 | 后续动作 |
| --- | --- | --- | --- |
| `verified` | success | 已核对通过（扫描器已读到新值） | 立即执行 |
| `mismatch` | danger | 核对不一致：扫描器仍读到旧值 | 重新核对、查看差异 |
| `unavailable` | warning | 已保存，下一轮生效；当前无法核对 | 立即执行、稍后重新核对 |
| `restart_required` | warning | 已保存，需重启扫描容器后生效 | 重启扫描容器 |

- **失败时清空上一条成功结果**，只显示失败阶段（校验/写入/回读/调度应用）+ 字段级错误 + 原始摘要。
- 409：模态「文件已被修改」→ 重新加载 / 取消（取消保留本地编辑）。
- 保存中：按钮 loading，表单可编辑但禁止再次提交；离开页面触发确认。

### 5.5 LogConsole

- 深色终端面板（两主题一致），等宽 12px，行高 18px，`white-space: pre-wrap; overflow-wrap: anywhere`。
- 顶部状态行：连接状态（连接中/实时/已暂停/已断开）+ 最后接收时间 + 行数 + 操作（暂停/继续、清空、下载）。
- 自动滚动仅在"实时且位于底部"时生效；用户上滚后暂停自动滚动，显示「回到底部（N 条新日志）」按钮。
- 超过 5000 行丢弃最旧行；暂停时不追加 DOM（仍接收并计数）。
- 断开时状态变 danger + 「正在重连」，绝不显示"实时"。
- 读屏：日志容器**不加** `aria-live`（高频播报会淹没读屏）；改为一个 `role="status"` 的摘要节点播报连接状态与行数变化。

### 5.6 Cron 编辑器

- 输入框（等宽）+ 4 个模板按钮（每 6 小时 / 每天 03:00 / 每 2 小时 / 每 30 分钟）。
- 实时预览未来 5 次（等宽时间，左对齐）；非法表达式就地 422 文案，保存按钮禁用。
- 6/7 段说明常驻：5 段=分时日月周；6 段第 6 位是年；7 段含秒。
- 保存结果沿用 SaveResultPanel；调度页额外展示 `apply-config.sh` 输出（折叠，最多 8 行）。

### 5.7 DataTable

- 表头 sticky；列宽按内容类型固定（时间 180、状态 120、操作 200、文本自适应）。
- 空数据：表体不显示"暂无数据"占位，改为页面级 `EmptyState`（见 5.9），并保留表头。
- 操作列按钮：主操作文字按钮，危险操作 danger 文字按钮；不可用时 disabled + tooltip 原因。
- 行内错误（如 IP 库行号）不塞进表格，使用页面级错误列表。

### 5.8 ConfirmDialog（危险操作）

- 标题：动作名（重启扫描容器 / 回滚配置 / 恢复备份）。
- 正文：影响（"会中断当前这一轮扫描，最多 150s 收尾"）+ 不可逆说明。
- 主按钮使用 danger（除"回滚"用 primary）；取消在左、确认在右。
- 容器操作另需 `X-Confirm: <action>`（后端契约），前端由对话框确认后自动附带。
- 若当前有轮次在跑：停/重启按钮仍可点，但文案明确"会中断当前轮次"。

### 5.9 EmptyState / ErrorState

| 状态 | 展示 |
| --- | --- |
| 加载中 | 骨架屏（表格 6 行 / 卡片 3 块），不用转圈遮罩 |
| 空 | 图标 + "尚无产物（下一轮扫描成功后生成）" + 产生条件 + 可选操作 |
| 错误 | danger 提示 + 原始原因摘要 + 「重试」；**不得**把错误显示成空状态 |
| 无权限/未登录 | 跳登录，不在页面内显示空态 |

### 5.10 Drawer / Dialog

- 版本历史、产物预览用右侧抽屉（宽 60%，最小 480px，最大 960px）；移动端全屏。
- 预览表格首列 sticky；文本预览等宽、可复制；Esc 关闭，焦点返回触发按钮。

## 6. 页面设计

### 6.1 总览 `/`

**目标**：5 秒内回答「扫描器活着吗、上一轮怎么样、下次什么时候跑」。

```
总览                                            [刷新]
[扫描容器]        [上次结果]        [下次执行]        [配置摘要]
 状态/健康/镜像    轮次/扫描/发布    未来 3–5 次       关键 6 项
 启动时间          摘要/耗时                           [查看全部参数]

最近轮次（表格 5 行）                                [查看全部]
```

- 扫描器不可用：卡片显示离线原因 + 「去日志」链接；其余卡片仍展示。
- 上次结果区分「扫描失败」与「发布失败」（两个独立退出码）。
- 无轮次：显示"尚无轮次记录，等待第一轮扫描"。
- 下次执行不可用：显示"调度表达式无效或未配置"，不显示假时间。

### 6.2 参数 `/config`

- 页头右侧：文件 mtime + `sha256 前 12 位` + 大小 + [版本历史] [重新加载]。
- 三个子标签；每个 tab 只渲染自己的分组（避免重复 DOM）。
- 折叠面板默认全展开；组标题显示该组未保存修改数。
- 底部操作栏：`未保存 N 项` + [取消] [保存]；`查看变更` 展开 diff 表。
- 敏感字段：无明文、无"显示"按钮；`configured=false` 时提示"未配置"。
- 409：模态重载；重载后仍保留用户输入？→ 不保留（服务端为准），但先让用户复制。

### 6.3 调度 `/schedule`

- 上方：当前生效 cron（只读等宽）+ 编辑框 + 模板。
- 中部：未来 5 次执行（列表，含时区）。
- 下方：保存结果 + `apply-config.sh` 输出（折叠）。
- 未保存离开确认；非法表达式禁用保存；容器离线时保存后提示"恢复后由 watcher 重载"。

### 6.4 运行 `/runs`

**立即运行**：
- 顶部一行：锁状态（空闲/运行中）+ [立即执行一轮]。
- 运行中：按钮禁用并显示"已有一轮在运行"；如为定时轮次，说明"定时任务正在执行，输出见日志页"。
- 输出区 LogConsole；结束后追加一行「结束：退出码 N」并刷新历史。
- 切页返回：若存在 `status=running` 且 `trigger=panel`，自动接回输出并提示"已接上进行中的轮次"。

**历史轮次**：
- 列：轮次 / 触发 / 开始 / 扫描 / 发布 / 耗时 / 状态 / 摘要。
- 状态三态：完成（success）、运行中（info，不显示耗时）、中断（warning，说明"容器停止或被杀"）。
- 点击行展开该轮摘要（不跳页）；空态"尚无轮次记录"。

### 6.5 日志 `/logs`

- 实时日志：状态行 + 过滤输入（本地包含匹配）+ 暂停/清空/下载 + LogConsole。
- 下载：右上角按钮（最近 5000 行）；下载失败显示错误而非静默。
- 容器不可用：页面显示"扫描容器不可用"错误 + 重试，不显示空日志。
- 暂停时仍计数；恢复后从当前缓冲区继续，不丢行。

### 6.6 产物 `/outputs`

- 顶部：本次读取时间 + 刷新；子标签 全部/订阅列表/明细表（按扩展名过滤）。
- 表格：文件 / 大小 / mtime / 操作（预览、复制、下载）。
- 订阅列表"复制"：成功后 toast；HTTP 非安全上下文无剪贴板时，回退为弹出只读文本域并全选。
- 预览抽屉：TXT 等宽前 200 行；CSV 表头 + 前 200 行；附 size/mtime/sha256 前 12 位。
- 空目录：EmptyState"尚无产物（下一轮扫描成功后生成）"。

### 6.7 IP 库 `/library`

- 顶部：行数 / 网段数 / 固定条目 / 跳过行 / mtime / hash 前 12 位。
- 编辑器：等宽 textarea + 行号槽（自绘，随滚动同步），错误行整行高亮（danger 背景 12% 透明）。
- 校验失败：错误列表「第 N 行：原因」可点击定位光标到该行；保留编辑内容。
- 保存成功：以服务端回读内容 + hash 刷新编辑器；显示"已保存"与备份提示。
- 备份页：表格（文件/时间/大小）+ 恢复（确认对话）；空态说明"保存时自动备份，最多 30 份"。

### 6.8 发布 `/publish`

- 参数：GIT_* 表单，令牌 fields 掩码；`GIT_PUSH_ENABLED=false` 时页头显示"已关闭"，但参数仍可编辑。
- 保存结果面板同参数页。
- 最近结果：轮次 / 结束时间 / 扫描退出码 / 发布退出码 / 摘要；区分"扫描成功但发布失败"。
- 无记录："尚无发布记录（完成一轮扫描后生成）"。

### 6.9 系统 `/system`

- 账号：当前密码 / 新密码 / 确认；成功与失败都要在表单内展示（不用仅 toast）。
- 审计：表格（时间/操作者/动作/详情/来源）+ 分页 50；空态"尚无操作记录"；加载失败显示错误 + 重试。
- 容器：三按钮（重启/停止/启动）+ 影响说明；确认对话框 + `X-Confirm`。
- 关于：面板版本/镜像/Python/Docker SDK + 密码重置命令（可复制）+ 备份含敏感值提示。

## 7. 交互状态机

### 7.1 表单保存（参数/调度/发布/IP 库）

```
idle ──编辑──▶ dirty ──保存──▶ saving ──成功──▶ result(saved)
  ▲             │                  │
  │             │取消              └─失败─▶ error(保留输入)
  └──重载/取消──┘                          │
                                            └─重试─▶ saving
```

- `dirty`：按钮启用；离开页面 → 确认对话框（离开/留下）。
- `saving`：按钮 loading、禁用重复提交；不锁定输入（可继续编辑，但保存用提交时快照）。
- 成功：以服务端回读刷新快照与 hash；结果面板保留到用户关闭或下次保存。
- 失败：清空旧成功结果；错误就地显示；输入不丢。
- 409：独立模态，先重载再允许保存。

### 7.2 手动运行

```
idle ──点击──▶ triggering ──202──▶ running ──done──▶ finished(退出码)
                    │                  │
                    ├─409 已有轮次─▶ idle(提示)     └─中断/断线─▶ interrupted/重连
                    └─503 不可用──▶ idle(错误)
```

- `running` 时禁用触发按钮；切页不终止执行（执行在容器内）。
- 结束后刷新历史与总览；失败显示退出码与"产物保留上一轮"。

### 7.3 SSE 连接

| 状态 | 触发 | UI |
| --- | --- | --- |
| connecting | 打开页面/重连 | info 点 + 「连接中」 |
| live | onopen | success 点 + 「实时」+ 最后接收时间 |
| paused | 用户暂停 | warning + 「已暂停」 |
| disconnected | onerror/服务端关闭 | danger + 「已断开，正在重连」 |

- 重连退避 1s→2s→4s→…→15s；运行输出流（一次性）不自动重连。
- 超过 10s 未收到任何日志但连接为 live：显示「可能停滞」提示（不改状态色）。

### 7.4 危险操作

```
点击 ─▶ 确认对话框（影响说明） ─▶ 确认 ─▶ 请求(带 X-Confirm) ─▶ 202/503
                        └─取消─▶ 无副作用
```

- 无确认头后端拒绝（400），前端不得绕过。
- 操作成功后写审计；失败展示原始原因。

## 8. 响应式

| 断点 | 布局 |
| --- | --- |
| ≥1280 | 四列卡片；表格全列；参数两组并排可选 |
| 768–1279 | 两列卡片；表格允许横向滚动（容器内，不是整页） |
| <768 | 单列；主标签横向滚动；状态条只保留图标+短文案；底部操作栏全宽；抽屉全屏 |

- 禁止页面级横向滚动；滚动只发生在表格/代码块内部。
- 触控目标 ≥44×44（移动端按钮、标签、分页）。
- 表格在窄屏优先隐藏"耗时/摘要"列，保留轮次/状态/退出码。

## 9. 可访问性（WCAG 2.2 AA）

- **对比度**：见 §3.2；浅色主题的绿色改用深绿文字。
- **焦点**：`:focus-visible` 统一 2px `--focus` 环 + 2px offset；禁止 `outline: none` 无替代。
- **键盘**：全部操作可 Tab；会话菜单/抽屉/对话框 Esc 关闭并归还焦点；确认对话框初始焦点在取消。
- **表单**：label 与控件 `for/id` 关联；错误通过 `aria-describedby` 关联到字段；必填/格式错误就地提示。
- **状态播报**：连接状态、保存结果用 `role="status" aria-live="polite"`；日志正文不播报；批量/高频变化不逐条播报。
- **图标**：装饰性 `aria-hidden="true"`；图标按钮必须有 `aria-label`。
- **表格**：`<caption>` 或标题关联；数字右对齐、文本左对齐；状态含文字。
- **减少动效**：遵循 `prefers-reduced-motion`，连接点动画与面板过渡退化。
- **缩放到 200%**：不出现内容截断与横向滚动。

## 12. 验收清单

- [ ] 深色/浅色两套主题下，正文、次要文字、按钮、状态标签对比度均 ≥4.5:1（非文本边界 ≥3:1）。
- [ ] 全站 Tab 可达；对话框/抽屉 Esc 关闭且焦点归还；无 `outline:none` 无替代。
- [ ] 状态不只靠颜色：在线/离线、verified/mismatch/unavailable/restart_required、done/running/interrupted 均有文字。
- [ ] 保存成功面板同时显示：写入、核对状态、生效方式、下次执行；任一缺失视为不通过。
- [ ] mismatch 时展示期望/实际差异；unavailable 时明确"当前无法核对"。
- [ ] 保存失败保留输入、清空旧成功结果、显示失败阶段。
- [ ] 离开有未保存修改的页面触发确认（参数/调度/IP 库/发布）。
- [ ] 日志/运行输出显示连接状态与最后接收时间；断开不显示"实时"；运行页切回可接回。
- [ ] 空态与错误态可区分；错误态有原因与重试。
- [ ] 375 / 768 / 1024 / 1440 无页面级横向滚动；触控目标 ≥44px。
- [ ] `prefers-reduced-motion` 下无状态动画。
- [ ] 无 emoji 图标；图标按钮有 aria-label；数字列等宽对齐。
